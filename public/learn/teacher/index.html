학교 앞 교통 수업 진행안

각 실습은 50분 수업을 기준으로 합니다. 학생용 화면을 함께 보면서 진행합니다. 학생의 통학 주소, 실제 시간표, 위치 기록은 수집하지 않습니다. 평가 근거는 질문의 구체성, 출처 확인, 결과 해석, 한계 설명입니다.

설명과 예상 오류

화면에 숫자가 나온다는 사실만으로 실시간 관측을 확인한 것은 아닙니다. 출처, 조회 시각, 값의 뜻을 함께 확인하도록 안내합니다.
키가 없는 환경에서는 신도림중학교와 당곡고등학교 예제로 진행합니다. 지하철 키와 버스 키는 서로 다릅니다. Google 지도가 연결되지 않으면 먼저 API 키의 웹사이트 제한, API 활성화와 결제 계정 연결을 확인합니다. 도보 버튼은 Google 지도이 설치된 휴대전화에서 확인합니다.
직선거리에는 담장과 횡단보도가 반영되지 않습니다. 예상 도착시각, 실제 도착시각, 자료 수신시각은 서로 다른 개념입니다. API 요청 한도와 수업 인원을 함께 고려해야 합니다.

평가 기록

  • 질문 설정: 대상과 필요한 결정을 구체적으로 적었는가?
  • 데이터 확인: 출처, 단위, 누락값과 갱신시각을 확인했는가?
  • 결과 해석: 화면의 숫자가 뜻하는 바를 설명했는가?
  • 한계 인식: 도보 경로, 출입구, 오래된 정보의 한계를 설명했는가?

공개 교재에는 시험 문항은행이나 학생 개인정보를 넣지 않습니다. 교사용 페이지도 공개 문서입니다.
