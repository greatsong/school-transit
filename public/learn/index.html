자료의 출처

학교 목록은 전국초중등학교위치표준데이터, 버스 정보는 서울시 정류소정보조회를 사용합니다. 지하철은 실시간 도착정보와 역사 마스터를 사용합니다. 도보 연결 규격은 Google Maps URL 공식 안내를 따릅니다.

  1. 앱에서 정류장 두 곳을 골라 이름과 정류소 번호, 버스의 방면을 비교합니다. 아래 예제는 실제 API 응답이 아닌 수업용 자료입니다.

3. 예상시간과 갱신 구별하기

1초마다 줄어드는 숫자는 마지막 응답을 바탕으로 계산한 예상값입니다. 매초 새로운 교통정보를 받은 결과가 아닙니다. 이 앱은 화면을 보는 동안 1분마다 조회하며, 3분이 지난 정보는 시간을 숨깁니다.

  1. 버스 즐겨찾기를 등록하고 지도 위 숫자가 줄어드는지 봅니다. 조회 시각과 숫자 변화가 서로 다른 주기로 움직이는지 확인합니다.
  2. ①을 AI에 요청하고 결과를 확인합니다. ③으로 불편한 점을 수정한 뒤 바뀐 결과를 기록합니다.
① 샘플 프롬프트
즐겨찾기한 버스와 지하철의 남은 시간을 분과 초로 보여줘. 조회한 시간을 바탕으로 숫자가 줄어들고, 화면을 열어둔 동안 1분마다 새 정보를 받아오면 좋겠어. 예상시간이라는 설명도 넣어줘.
② AI가 준 코드 예시
const prediction = 90;
const elapsed = 11;
const remaining = prediction - elapsed;
console.log(`${Math.floor(remaining / 60)}분 ${remaining % 60}초`);
③ 프롬프트 개선 예시
숫자가 0이 되었다고 도착을 확정하지 말아줘. 오래된 정보에는 새로고침이 필요하다는 설명을 보여줘. 실제 도착을 확인한 기록과도 구별해줘.
판단하고 설명하기

4. 즐겨찾기와 공유 범위 정하기

학교, 정류장, 노선, 지하철역 선택은 이 브라우저에 저장합니다. 개인 시간대 설정은 공유 링크에 넣지 않습니다. 공유 링크는 받은 사람도 읽을 수 있는 공개 정보입니다.

  1. 정류장과 지하철역을 즐겨찾기한 뒤 페이지를 다시 엽니다. 우리 학교 공유 버튼으로 만든 주소를 다른 브라우저에서 열어 같은 학교와 즐겨찾기가 보이는지 확인합니다.
  2. ①을 AI에 요청하고 결과를 확인합니다. ③으로 불편한 점을 수정한 뒤 바뀐 결과를 기록합니다.
① 샘플 프롬프트
친구에게 우리 학교 지도를 공유하고 싶어. 선택한 정류장과 노선, 지하철역이 같은 화면에 나오게 해줘. 나의 시간대 설정과 다른 학교 목록은 공유하지 말아줘.
② AI가 준 코드 예시

const shared = {school:saved.school, stations:saved.stations};

③ 프롬프트 개선 예시
공유 링크로 들어온 친구의 기존 설정은 그대로 유지해줘. 공유 지도를 보고 있는 동안 바꾼 내용이 개인 설정을 덮어쓰지 않게 해줘.

5. 지도와 도보 경로 확인하기

직선거리와 실제 도보거리는 다릅니다. 학교 중심 좌표는 교문 위치와 다를 수 있고, 지하철역 좌표는 출입구 위치와 다를 수 있습니다. Google 지도에 출발지와 도착지를 전달하여 제공되는 경로를 확인합니다. 한국 도보 경로는 API 지원이 제한되므로 앱에서는 직접 입력한 소요시간으로 계산합니다.

  1. 정류장을 선택해 골목이 보일 정도로 확대되는지 확인합니다. 휴대전화에서 학교에서 걸어가기 버튼을 눌러 Google 지도의 출발지와 도착지를 확인합니다.
  2. ①을 AI에 요청하고 결과를 확인합니다. ③으로 불편한 점을 수정한 뒤 바뀐 결과를 기록합니다.
① 샘플 프롬프트
정류장을 고르면 골목이 보일 정도로 확대해줘. 학교에서 그 정류장까지 걸어갈 길은 Google 지도으로 연결해줘. 도보 소요시간을 확인하지 못했으면 임의의 숫자를 보여주지 말아줘.
② AI가 준 코드 예시
const directMeters = 300;
console.log(`직선거리 ${directMeters}m`);
console.log("도보 경로와 소요시간은 지도에서 별도 확인");
③ 프롬프트 개선 예시
학교 좌표와 교문이 다를 수 있다는 안내를 넣어줘. 지하철은 역 입구부터 승강장까지 가는 시간이 더 필요하다는 점도 보여줘.

확장. 다음 환승편을 탈 수 있을까요?

경로 설정에서 등교·하교 시간을 나누고 이동 순서를 저장합니다. 개인 통학 경로 대신 가상의 학교 간 경로로 실습합니다. 도보·탑승시간은 직접 입력한 예상값이며, 서울시 도착정보에서 확인할 수 있는 차편만 계산에 사용합니다.

① 샘플 프롬프트
지금부터 승차 지점까지 도보 3분, 탑승 여유 1분이 필요해. 2분 후와 6분 후 오는 버스 중 탈 수 있는 차편을 골라줘. 다음 환승편의 정보가 없으면 전체 도착시각을 임의로 계산하지 말아줘.
② AI가 준 코드 예시
const walking = 3 * 60;
const buffer = 1 * 60;
const arrivals = [2 * 60, 6 * 60];
const next = arrivals.find(seconds => seconds >= walking + buffer);
console.log(next === undefined ? "차편 확인 필요" : `${next / 60}분 후 차편`);
③ 프롬프트 개선 예시
버스 탑승 12분과 환승 도보 4분을 더해서 다음 승차 지점 도달시각을 구해줘. 모든 차편은 지금을 기준으로 비교하고, 오래된 정보·운행 종료·방면이 다른 차편은 제외해줘.
