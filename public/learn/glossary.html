학교 앞 교통

용어

API
정해진 요청으로 다른 서비스의 데이터를 받는 방법입니다.
인증키
데이터 서비스의 이용 권한을 확인하는 값입니다. 공개 코드에 넣지 않습니다.
환경변수
실행 환경에서 프로그램에 전달하는 설정입니다. 서버의 키를 코드와 분리할 때 사용합니다.
localStorage
현재 브라우저에 설정을 저장하는 공간입니다. 다른 기기와 자동으로 동기화되지 않습니다.
도착예정
교통 상황을 바탕으로 예상한 도착 시간입니다. 실제 도착을 관측한 기록과 다릅니다.
직선거리
두 좌표를 바로 연결한 거리입니다. 도보 경로의 길이와 다를 수 있습니다.
방면
교통편이 진행하는 방향입니다. 같은 정류장 이름이나 노선 번호만으로 판단하지 않습니다.
캐시
이미 받은 응답을 일정 시간 다시 사용하는 저장 방식입니다.
예제 모드
인증키 없이 기능을 연습하는 화면입니다. 실제 운행 정보가 아닙니다.
배포
다른 사람이 주소로 접속할 수 있도록 프로그램을 서버에 올리는 과정입니다.
