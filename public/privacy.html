개인정보와 데이터 안내

앱에 입력하지 않는 정보

회원가입, 이름, 연락처, 집 주소, 현재 위치를 요청하지 않습니다. 광고·분석 SDK와 추적 쿠키를 넣지 않았습니다.

이 브라우저에 저장하는 설정

등록 학교, 버스 정류장·노선·방향, 지하철역 즐겨찾기, 시간대별 기본 버스 정류장, 이동 경로와 직접 설정한 도보·탑승 시간을 localStorage에 저장합니다. 다른 기기로 자동 전송하지 않습니다. 학교 설정의 초기화 버튼으로 이 앱의 저장 정보를 삭제할 수 있습니다.

네트워크 요청

도착정보를 조회할 때 서버에는 공개 학교·정류장·역 식별자를 전달합니다. 서버는 원본 교통정보를 메모리에 잠시 보관하며 개인별 이동 이력을 만들지 않습니다. 사용자의 저장된 시간대와 전체 경로 목록은 서버로 보내지 않습니다. 경로에서 조회할 승차 지점 식별자는 도착정보 요청에 사용됩니다.

호스팅 업체와 외부 지도 서비스는 요청 처리 과정에서 IP 주소와 접속 로그를 처리할 수 있습니다. 앱이 개인정보 입력을 요구하지 않는다는 설명은 모든 외부 서비스가 접속 정보를 처리하지 않는다는 뜻은 아닙니다. Google 지도를 연결하기 전에는 OpenStreetMap 타일을 사용합니다.

공유 링크

공유 링크에는 현재 학교와 그 학교에서 선택한 버스·지하철이 담깁니다. 개인 시간대·이동 경로와 다른 학교 목록은 제외합니다. 링크를 받은 사람도 다시 전달할 수 있습니다. 링크의 설정은 주소의 # 뒤에 들어갑니다.

정보의 한계와 출처

숫자는 도착예정입니다. 버스는 API 수신 시각, 지하철은 공식 응답의 생성 시각을 기준으로 계산하며 오래된 정보는 숨깁니다. 1분마다 조회하므로 초 단위 관측값은 아닙니다. 실제 도착 이력을 기록하지 않습니다.

서울시 버스 정류소정보조회, 지하철 실시간 도착정보·역사 마스터, 전국초중등학교위치표준데이터를 사용합니다. 지도에는 해당 공급자의 출처를 표시합니다. 자료 링크는 교재의 출처 목록에서 확인합니다.
